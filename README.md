# kr-stock-monitor

한국투자증권 공식 HTTPS REST API로 국내주식 **KRX 현재가를 주기 조회**하는 VS Code 데스크톱 확장입니다. 기본 조회 간격은 5초이며 평문 WebSocket을 사용하지 않습니다.

## 설치와 시작

1. VS Code 확장 화면(`Ctrl+Shift+X`)의 `…` → **VSIX에서 설치…**에서 `kr-stock-monitor-0.1.2.vsix`를 선택합니다.
2. `Ctrl+Shift+P` → **KR Stock Monitor: 관심 종목 추가**에서 6자리 코드와 이름을 등록합니다.
3. **KR Stock Monitor: 실전 API 키 등록**에서 실전 APP KEY와 APP SECRET을 입력합니다. 입력은 가려지며 VS Code 보안 저장소에 함께 저장합니다.
4. **KR Stock Monitor: HTTPS KRX 시세 조회 시작**을 실행합니다. 자동 연결하지 않으므로 VS Code를 다시 열면 연결 명령을 실행하세요.
5. 기본값은 **모든 종목 동시 표시**입니다. **KR Stock Monitor: 표시 방식 선택** 또는 상태 표시줄 클릭 → **표시 방식 선택**에서 모두 표시/순환 표시를 바꿀 수 있습니다. 가격은 HTTPS 조회에 성공할 때 갱신합니다. 마우스를 올리면 전체 관심 종목과 시각을 확인합니다.

계좌/API 신청은 [KIS Developers](https://apiportal.koreainvestment.com/intro)의 API신청에서 진행합니다. 계좌·ID 연결 후 실전 Open API를 신청하고 발급받은 키를 준비하세요. 키를 채팅·Git·`settings.json`에 넣지 마세요. 등록 취소 시 기존 키를 유지하며, 삭제는 **KR Stock Monitor: API 키 삭제**에서 확인 후 수행합니다.

## 설정 예시

종목 추가·삭제 명령 대신 사용자 `settings.json`에서 아래 설정을 편집해도 됩니다. 기존 KR Stock 확장의 `krStock.*` 설정과 별개입니다.

```json
{
  "krStockMonitor.stocks": [
    { "code": "204320", "name": "HL만도" },
    { "code": "000990", "name": "DB하이텍" },
    { "code": "108860", "name": "셀바스AI" }
  ],
  "krStockMonitor.displayMode": "all",
  "krStockMonitor.rotationInterval": 5,
  "krStockMonitor.pollingInterval": 5
}
```

`displayMode`는 `"all"`(모두 표시, 기본값) 또는 `"rotate"`(순환 표시)입니다. 모두 표시에서는 종목을 ` | `로 구분합니다. 순환 표시에서는 기본 5초마다 한 종목씩 바뀌며 클릭 메뉴에서 표시할 종목을 선택할 수도 있습니다. 순환 간격은 1~60초 정수이며 순환 표시에서만 적용합니다. 창이 좁으면 동시 표시가 길어질 수 있으므로 순환 표시를 선택할 수 있습니다.

종목 코드는 중복 없는 6자리, 이름은 1~40자로 입력합니다. 연결 중 종목 목록을 바꾸면 새 목록으로 다시 연결합니다. 표시 방식·순환 간격 변경은 기존 시세와 조회를 유지한 채 바로 적용합니다. `pollingInterval`은 5~300초 정수로 설정하며 화면 순환 간격과 별개입니다. 조회 간격 변경은 토큰을 재발급하거나 표시 가격을 지우지 않고 다음 조회에 반영합니다.

## 상태와 확인 방법

- 연결 명령을 실행하면 저장된 키로 REST 접근토큰을 확보하고 첫 현재가 조회를 시작합니다. HTTP 연결 성공과 실제 시세 응답 검증 성공을 구분합니다.
- 종목은 설정 순서대로 조회하고 요청 시작 사이에 최소 1초를 둡니다. 세 종목을 5초 주기로 조회하는 경우 정상 상태에서 평균 약 초당 0.6건입니다. 응답이 느리거나 종목이 많으면 실제 주기는 늘어납니다.
- 툴팁에 종목별 **마지막 조회 시각(KST)**을 표시합니다. 실제 체결 시각이 아니며, 장외 조회 성공도 새로운 체결을 뜻하지 않습니다.
- 조회 실패 시 마지막 성공 가격과 조회 시각을 유지하고 오류·부분실패를 표시합니다. 실패 종목의 이전 가격을 새 조회 성공으로 처리하지 않습니다.
- 일시 오류는 5/10/20/40/60초 대기 후 최대 5회 재시도하고 여섯 번째 연속 실패 회차에서 중단합니다. 전체 종목 조회 성공 시 실패 횟수를 초기화합니다. 서버의 더 긴 `Retry-After`가 있으면 해당 회차의 남은 요청도 멈추고 기다립니다.
- 키·권한·응답 형식 오류는 중단하며 평문 WS로 전환하지 않습니다. 인증서 검증 실패에서도 보안을 완화하거나 다른 주소로 우회하지 않습니다.
- 실패 원인은 **KR Stock Monitor: 연결 로그 보기**에서 확인합니다. 키·토큰·인증 헤더·요청 본문·원문 응답은 기록하지 않습니다.
- 여러 창·다른 프로그램의 요청은 계좌별 한도에 합산됩니다. 우선 한 창에서 사용하세요. 창 사이 최초 토큰 발급이 경합하면 발급 대기가 생길 수 있습니다.

**KR Stock Monitor: 가상 시세 데모 시작**은 키·외부 접속 없이 화면을 확인하는 모드입니다. `[데모]`를 표시하며 실제 오류 시 자동 전환하지 않습니다. 실전 조회로 전환하면 가상 가격을 지웁니다.

## 인증과 보안

토큰 발급은 `https://openapi.koreainvestment.com:9443/oauth2/tokenP`, 현재가는 같은 HTTPS 호스트의 `/uapi/domestic-stock/v1/quotations/inquire-price`를 사용합니다. KRX 시장 구분 `J`, TR ID `FHKST01010100`을 사용합니다. 인증서 검증을 유지하고 리다이렉트를 거절하며 요청마다 10초 제한을 적용합니다.

원본 APP KEY·APP SECRET은 기존 VS Code SecretStorage 항목 `kis.real.credentials.v1`에 유지합니다. REST 요청 규격에 따라 토큰 발급 본문과 현재가 요청의 HTTPS 헤더에서 키를 사용합니다. 키·토큰은 URL·로그·설정 파일에 넣지 않습니다.

REST 접근토큰과 만료정보·재발급 대기정보는 별도 SecretStorage 항목 `kis.real.restToken.v1`에 암호화 저장해 재시작·다른 창에서도 재사용합니다. 연결 끊기는 요청·타이머를 중단하며 캐시는 만료까지 유지합니다. **API 키 삭제**는 원본 키와 파생 캐시를 삭제하지만 한국투자 서버의 키를 폐기하는 동작은 아닙니다. 키 교체 중 도착한 이전 발급 응답도 저장하지 않습니다.

토큰 발급 주기는 공식 공지와 FAQ의 설명이 달라 보수적으로 최소 5분 간격을 적용합니다. 만료되지 않은 토큰은 실제 만료정보를 기준으로 재사용하고 매번 발급하지 않습니다. 최초 발급 실패·토큰 만료 시 최대 수분의 인증 대기가 생길 수 있습니다. 더 긴 서버 대기 지시는 우선합니다.

로컬 저장 암호화는 같은 사용자 권한의 악성 프로그램·PC 침해를 완전히 차단하지 않습니다. HTTPS도 신뢰된 인증서를 사용하는 검사 프록시나 침해된 PC까지 방어하는 보장은 아닙니다.

## 업데이트와 범위

0.1.0/0.1.1을 먼저 제거할 필요 없이 같은 VS Code에서 0.1.2 VSIX를 설치할 수 있습니다. 확장 ID, 원본 키 저장 항목, 관심종목과 동시/순환 설정 이름을 유지하므로 같은 환경에서는 기존 정보를 재사용합니다. 필요하면 창을 다시 로드한 뒤 **HTTPS KRX 시세 조회 시작**을 실행하세요. 이전 창에서 실행 중인 0.1.1 WS 연결은 새 VSIX 파일 생성만으로 종료되지 않으므로 업데이트 시 기존 조회를 끊으세요.

이번 버전은 국내주식 KRX 현재가 조회입니다. NXT·통합 시세, 차트, 지수·환율, 해외주식, 주문·계좌·잔고 조회, 개인 주문 체결통보는 포함하지 않습니다. 주기 조회이므로 틱 단위 실시간 갱신과 다릅니다.

개인용 로컬 VSIX입니다. Marketplace에 게시하지 않았으며 라이선스는 `UNLICENSED`입니다. 재배포·공개 서비스의 시세 이용 조건은 별도로 확인해야 합니다.

## 개발과 검증

Node 24, VS Code 1.140 이상을 대상으로 합니다. PowerShell에서:

```powershell
npm.cmd ci --ignore-scripts
npm.cmd test
npm.cmd run package
```

F5로 개발 호스트를 열 수도 있습니다. 자동 테스트는 합성 HTTPS 응답·가상 시계·SecretStorage/VS Code 대역을 사용하며 외부 API에 접속하지 않습니다. 패키징 성공과 실제 API 조회 성공은 별개입니다.

실제 조회 확인은 저장된 키 유지 → 한 창에서 조회 시작 → 가격과 조회 시각 변화 → 종료 순서로 수행하고 한국투자 화면과 **KRX 기준**을 맞춰 비교하세요. NXT·통합 시세와 가격이 다를 수 있습니다.

중단하려면 연결 끊기 명령 후 확장을 비활성화하세요. 삭제 전에 키 삭제 명령을 별도로 실행할 수 있습니다. 기존 KR Stock 확장과 사용자 설정은 자동으로 수정하지 않습니다.
